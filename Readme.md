# E-Commerce Dashboard using Google Sheets

## 📊 Project Overview

This project is an **E-Commerce Sales Dashboard created using Google Sheets** to analyze and visualize sales data. The dashboard provides an interactive view of key business metrics and helps identify sales trends, product performance, and customer insights.

## 🎯 Objectives

* Analyze e-commerce sales performance
* Track important business KPIs
* Identify top-performing products and categories
* Understand sales trends over time
* Present data in a simple and interactive dashboard

## 🛠️ Tools & Technologies

* **Google Sheets**
* Data Cleaning & Transformation
* Pivot Tables
* Charts & Visualizations
* Formulas and Functions
* Data Analysis

## 📌 Key Features

* Total Sales and Order Analysis
* Sales by Category
* Sales by Product
* Monthly/Time-based Sales Trends
* Interactive charts and visualizations
* KPI-based performance overview
* Easy-to-understand dashboard layout

## 📈 Dashboard Insights

The dashboard helps users quickly understand:

* Overall e-commerce sales performance
* Which products and categories generate the most sales
* Changes in sales over time
* Areas of strong and weak performance
* Key patterns within the dataset
